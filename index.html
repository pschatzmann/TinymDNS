TinymDNS

[](LICENSE)

TinymDNS is a header-only mDNS (RFC 6762) library for Arduino. A single object registers a local hostname, answers name.local queries, announces itself on the network, and resolves other .local names. It works with any Arduino UDP implementation, such as WiFiUDP or EthernetUDP.

It provides:

  • **TinymDNS**: registers a hostname and IPv4 address, answers queries, announces the address, and resolves .local names.
  • **MDNSResult**: the outcome of the most recent resolve() call.

Installation

Arduino IDE

Download the library as a ZIP file and add it with Sketch → Include Library → Add .ZIP Library…, or clone it into your Arduino libraries folder:

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinymDNS.git

PlatformIO

lib_deps = https://github.com/pschatzmann/TinymDNS.git
