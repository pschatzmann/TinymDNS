Detailed Description

Header-only mDNS responder and resolver using a generic Arduino UDP object.

The object owns one UDP socket on port 5353, joined to the mDNS multicast group 224.0.0.251. Queries for the registered name are answered in loop() and resolve(); resolve() blocks until an answer arrives or the timeout expires.
