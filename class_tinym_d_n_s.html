Detailed Description

Header-only mDNS responder and resolver using a generic Arduino UDP object.

The object owns one UDP socket on port 5353, joined to the mDNS multicast group 224.0.0.251. Queries for the registered name are answered in loop() and resolve(); resolve() blocks until an answer arrives or the timeout expires.

Member Enumeration Documentation

◆ Event

enum class Event
strong

Kind of mDNS event reported to the EventCallback.

Enumerator
Query 

A host asked for name; ip is the asker's address.

Announcement 

A host announced/answered an A record (TTL > 0): name resolves to ip.

ReplyReceived 

A host replied to our own resolve() query: name is at ip.

ReplySent 

We answered a query for our hostname; name is our FQDN, ip the asker.

Goodbye 

A host withdrew an A record (TTL 0, RFC 6762 section 10.1): name left ip.
